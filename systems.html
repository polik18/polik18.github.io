Category 03 · Systems

先看懂問題，再選擇安全的下一步。

系統類專案不只顯示分數或按下掃描，而是把硬體瓶頸與救援風險翻譯成能採取行動的資訊。診斷重視可解釋性；救援則把避免二次傷害放在第一位。

BENCHMARK01

YieldVitals

一套在瀏覽器中執行的八軸效能與硬體診斷平台。除了跑分，也會整理裝置資訊、指出相對瓶頸，並給出適合不同裝置類型的改善方向。

  • 8 軸測試
  • Web Worker
  • WebGL
  • 30 國語系
  • CPU 邏輯、字串解析與多核心測試
  • RAM 分配、加密吞吐與本機儲存 I/O
  • DOM 重繪、WebGL GPU 與網路下載
  • 辨識核心數、記憶體、GPU 與畫面環境
  • 用雷達圖呈現長短板與裝置適用情境
  • 支援複製文字與下載 JSON 原始報告

RECOVERY02

Polik Recovery

以「來源磁碟唯讀」為核心原則的資料救援專案。公開頁面提供架構、操作與風險說明，桌面工具針對 NTFS、exFAT、APFS 與檔案特徵掃描建立復原流程。

  • 唯讀優先
  • NTFS／exFAT／APFS
  • Raw Carving
  • SHA-256 稽核
  • 避免將救援結果寫回來源磁碟
  • 解析檔案系統結構與虛擬檔案樹
  • 結構毀損時以檔案特徵進行深度掃描
  • 支援 PNG、JPEG、PDF、ZIP、MP4 等格式
  • 救援輸出附雜湊清單供完整性檢查
  • 提供新手指南與進階架構說明

Safety notes

兩種問題，兩種處理原則

效能變慢

先建立可比較的基準

關閉不必要程式、固定電源與散熱條件，多跑幾次 YieldVitals，避免用單次結果直接判定硬體故障。

檔案遺失

立即停止寫入來源

不要在原磁碟安裝工具、下載檔案或存回救援結果；新的寫入可能覆蓋仍可恢復的資料。

高價值資料

先評估再動手

異音、無法辨識、加密或物理損壞時，軟體掃描不一定安全，應先考慮專業救援與完整映像。
