Windows 時間不同步？脫離 AD 網域「網際網路時間」消失一鍵修復（附 .bat 批次檔）

作者：小黃老師（C樂遊）・發表於 2026-11-16

公司電腦汰換或退出企業網域後，系統時間卻越走越慢，連開個網頁都跳出「您的連線不是私人連線」的憑證警告？想手動調整卻發現權限不足，連控制台裡的「網際網路時間」分頁都憑空消失！別擔心，這篇手把手教學將帶你免靠網域管理員，僅用本機管理員權限，搭配一鍵修復批次檔，三分鐘徹底解除校時鎖定。

在企業資訊維運或二手商務電腦交接時，最讓人頭疼的隱形地雷之一就是「Windows 系統時間不同步」。很多朋友一開始以為只是小事，直到某天打開瀏覽器發現所有網站都顯示「您的連線不是私人連線（憑證尚未生效或已過期）」，甚至連通訊軟體無法登入、檔案修改時間全部錯亂，才驚覺事態嚴重。

更讓人崩潰的是，當一般同事想自己進系統設定調整時間時，畫面直接跳出「權限不足」；好不容易請管理者登入，打開傳統控制台的「日期與時間」，卻發現原本應該在最右邊的「網際網路時間（Internet Time）」分頁竟然憑空消失了！今天這篇文章，就用最白話的方式帶你拆解背後的技術原因，並提供能直接複製執行的自動修復工具。

1. 為什麼電腦脫離 AD 網域後，時間會失準又鎖死？

這起怪現象的罪魁禍首，其實是過去企業環境中 Active Directory（AD 網域服務） 留下來的設定殘留。當電腦曾經加入過企業網域，就算後來主機搬離公司、或原本的 AD 伺服器已經退役拆除，Windows 內部依然會死守著舊規則：

🔒 校時模式被鎖在 NT5DS

加入網域時，系統會將對時模式從一般的網際網路（NTP）強制改為網域階層（NT5DS）。在此模式下，微軟會刻意隱藏控制台的「網際網路時間」分頁，避免員工私自亂改對時主機。

🔋 找不到伺服器只能靠主板硬撐

因為原本的 AD 網域控制站已經不存在，電腦每次想對時都撲空，最後只好退而求其次改用主機板上的 CMOS 時鐘（Local CMOS Clock），時間誤差自然越滾越大。

🛡️ 一般使用者權限受限

基於資安稽核與防竄改設計，Windows 預設就不允許一般標準使用者（Standard User）修改系統時間。過去有網域自動對時沒感覺，一旦自動對時失效，一般人就完全動彈不得。

2. 權限大哉問：沒有網域管理員，靠本機管理員夠用嗎？

很多人在處理這類問題時，最擔心的就是：「原本的網域管理員（Domain Admin）帳密早就找不到了，我手上只有這台電腦的本機管理員（Local Administrator）帳號，這樣有辦法解開網域的群組原則鎖定嗎？」

答案是：完全足夠！百分之百可以解決，完全不需要網域管理員權限。

原因很簡單：網域群組原則（GPO）的運作原理，是把政策寫進這台電腦的本機登錄檔（Registry）中。既然原本的 AD 伺服器已經不存在，就不會再有新的網域原則從遠端派送下來覆蓋你的設定。只要你擁有這台電腦的本機管理員權限，就具備修改 HKEY_LOCAL_MACHINE 系統登錄檔與重啟背景服務的最高權限，足以把殘留的網域枷鎖徹底清除。

帳號權限層級能否手動調時間能否解除 AD 校時鎖定實務建議
一般使用者 (Standard User)❌ 無法修改❌ 權限不足日常工作使用，修復後無需開放權限
本機管理員 (Local Admin)✅ 可以修改✅ 完全足夠執行本篇修復指令的最佳角色
網域管理員 (Domain Admin)✅ 可以修改✅ 可以解除AD 伺服器已不存在時無需使用

3. 動手前必看！資深工程師的兩個保命提醒

在開始輸入指令之前，請先花 30 秒確認以下兩件事，能幫你避開許多慘痛的維運災難：

⚠️ 提醒一：千萬別為了修時間而把電腦「退出網域」！如果這台電腦的使用者目前仍是透過「快取的舊網域帳號」登入桌面，請直接套用本篇的指令修復即可，千萬不要手癢去系統內容把網域改成工作群組（Workgroup）。一旦退出網域，原本的網域帳號會立刻失效；萬一你手邊剛好沒有記下本機管理員密碼，整台電腦就會直接鎖死無法登入！

⚠️ 提醒二：檢查主機板 CMOS 電池是否沒電。如果你發現這台電腦每次只要拔掉電源線或關機過夜，時間就會直接跳回 2019 年或 2000 年，代表主機板上的 CR2032 鈕扣電池已經耗盡。建議先花幾十元更換一顆新電池，再搭配下方的網路自動校時，才能做到萬無一失。

4. 手動修復四步驟：解除 NT5DS 鎖定並改用國家標準時間

如果你想清楚掌握系統底層到底改了哪些地方，可以依照下面 4 個步驟手動執行。我們會將校時來源指定到台灣官方權威的 國家時間與頻率標準實驗室（tock.stdtime.gov.tw），在台灣本地連線速度最快、準確度也最高。

  1. 以系統管理員身分開啟命令提示字元：點擊 Windows 工作列搜尋圖示，輸入 cmd，對著「命令提示字元」按右鍵，選擇「以系統管理員身分執行」（若跳出 UAC 視窗，請輸入本機管理員帳號密碼）。
  2. 刪除殘留的網域群組原則時間機碼：輸入以下指令清除過去網域強制派送的限制（若畫面提示找不到指定的登錄機碼，代表這台電腦沒有額外原則鎖定，直接忽略進行下一步即可）：
    reg delete "HKLM\SOFTWARE\Policies\Microsoft\W32Time" /f
  3. 解除 NT5DS 鎖定並綁定台灣國家標準時間伺服器：依序執行這兩行指令，把同步模式改回外部網路 NTP，並同時設定主伺服器與備援伺服器：
    reg add "HKLM\SYSTEM\CurrentControlSet\Services\W32Time\Parameters" /v Type /t REG_SZ /d NTP /f
    w32tm /config /manualpeerlist:"tock.stdtime.gov.tw,0x9 time.stdtime.gov.tw,0x9 clock.stdtime.gov.tw,0x9" /syncfromflags:manual /reliable:YES /update
    💡 技術小知識：網址後方的 ,0x9 是微軟官方 w32tm 工具規範 建議的旗標參數（0x1 特殊輪詢間隔 + 0x8 Client 模式），能大幅降低外部網路校時逾時失敗的機率。
  4. 將時間服務設為開機自動啟動並強制同步：最後這三行指令會確保以後每次開機，Windows 都會自己在背景對時，並立刻觸發一次校準：
    sc config w32time start= auto
    net stop w32time && net start w32time
    w32tm /resync /force

5. 懶人救星：一鍵修復 .bat 批次檔（直接複製就能用）

如果你手邊不只有一台電腦要處理，或者不想一行一行慢慢敲指令，我已經幫大家把上述所有步驟打包成一份防呆自動腳本，還內建了「管理員權限自動檢查機制」。只要複製下方完整代碼，存成 .bat 批次檔，滑鼠右鍵執行就能一次搞定！

@echo off
chcp 65001 >nul
title Windows 脫離 AD 網域時間同步一鍵修復工具
 
:: 檢查是否具備系統管理員權限
net session >nul 2>&1
if %errorLevel% neq 0 (
    echo [錯誤] 權限不足！
    echo 請關閉此視窗，對著批次檔按右鍵並選擇「以系統管理員身分執行」。
    echo.
    pause
    exit /b 1
)
 
echo ==============================================================
echo   開始解除 AD 網域校時鎖定並切換至台灣國家標準時間伺服器
echo ==============================================================
echo.
 
echo [1/5] 清除殘留的網域群組原則 (GPO) 時間設定...
reg delete "HKLM\SOFTWARE\Policies\Microsoft\W32Time" /f >nul 2>&1
 
echo [2/5] 將時間同步模式從網域 (NT5DS) 強制切換為外部網路 (NTP)...
reg add "HKLM\SYSTEM\CurrentControlSet\Services\W32Time\Parameters" /v Type /t REG_SZ /d NTP /f >nul
 
echo [3/5] 設定時間伺服器為台灣國家標準時間 (tock.stdtime.gov.tw)...
w32tm /config /manualpeerlist:"tock.stdtime.gov.tw,0x9 time.stdtime.gov.tw,0x9 clock.stdtime.gov.tw,0x9" /syncfromflags:manual /reliable:YES /update >nul
 
echo [4/5] 設定 Windows Time 服務為「自動啟動」並重新啟動服務...
sc config w32time start= auto >nul
net stop w32time >nul 2>&1
net start w32time >nul
 
echo [5/5] 立即強制執行網路時間校準...
w32tm /resync /force
 
echo.
echo ==============================================================
echo   修復完成！目前的時間同步來源為：
w32tm /query /source
echo ==============================================================
echo.
pause

📝 批次檔製作與執行教學：

  1. 在電腦桌面上按滑鼠右鍵 → 新增 → 文字文件，開啟記事本並完整貼上上方黑色區塊內的所有程式碼。
  2. 點擊記事本左上角的「檔案」 → 「另存新檔」。
  3. 下方的「存檔類型」務必切換為「所有檔案 (*.*)」，編碼選擇 UTF-8，檔名輸入 Fix_Windows_Time.bat 後按下儲存。
  4. 回到桌面，對著剛剛建立的 Fix_Windows_Time.bat 按右鍵，點選「以系統管理員身分執行」，看到畫面顯示「命令已經成功完成」並列出 tock.stdtime.gov.tw,0x9 就大功告成了！

6. 修復後如何驗證成功？常見疑難排解 Q&A

執行完腳本後，你可以透過兩個地方雙重確認設定是否已經生效：第一是打開傳統日期時間視窗（按下 Win + R 輸入 timedate.cpl），你會發現消失已久的「網際網路時間」分頁重新回來了；第二則是在命令提示字元輸入 w32tm /query /source，只要看到回傳 tock.stdtime.gov.tw,0x9（不再是 Local CMOS Clock），就代表對時通道已經完全打通！

Q1：執行最後一步強制校準時，出現「電腦沒有重新同步，因為沒有可用的時間資料」怎麼辦？
這通常有兩個原因：第一是電腦目前時間與真實時間差距過大（例如差了好幾年），Windows 基於安全保護機制會拒絕一次跨度太大的自動調整。這時只要用管理員權限先手動把年份與日期調到接近今天，再重新執行一次 w32tm /resync /force 就能順利同步；第二則是公司或防毒軟體防火牆擋住了 UDP 123 連接埠，請確認網路環境允許對外連接 NTP 服務。

Q2：修復完成後，一般使用者以後還需要手動去調時間嗎？
完全不需要！因為我們的腳本已經透過 sc config w32time start= auto 將 Windows Time 服務設定為開機自動啟動。往後只要電腦有連上網際網路，系統就會在背景自動與台灣國家標準時間伺服器保持同步，一般使用者完全不需要（也不建議開放）手動修改系統時間的權限，既安全又省心。

📌 技術操作與系統設定免責聲明本文所提供之指令與批次檔（.bat）涉及 Windows 系統服務調整及本機登錄檔（Registry）機碼修改，僅適用於已合法脫離企業 AD 網域且具備本機管理員授權之電腦設備。執行任何系統層級修改前，請務必確認指令內容並妥善保存本機管理員帳號資訊；若電腦仍受現行企業資安政策納管，請先聯繫貴單位資訊管理人員，切勿擅自變更網域設定。
