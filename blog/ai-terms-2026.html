【2026 AI專有名詞全攻略】從7B/A3B模型代碼、RAG到DiT影音生成，4階級秒測你的AI實力！

作者：小黃老師（C樂遊）・發表於 2026-09-02

這兩年生成式 AI 以前所未有的速度席捲全球，身邊的朋友或工作夥伴開口閉口都是提示詞、模型型號與算力。但當大家在討論「7B、35B、A3B、Instruct、AWQ」到底代表什麼，或者話題從純文字問答延伸到多模態系統、自主代理人、甚至是極度複雜的「AI 影片去噪與 DiT」時，許多人常常被排山倒海的英文縮寫搞得一頭霧水。到底該如何精準衡量一個人對 AI 是「停留在下咒語的初學者」，還是「具備全端軟硬體整合實力的頂尖架構師」？這篇文章將日常最常碰到的操作名詞放最前線，由淺入深、抽絲剝繭地重組為完整的評測字典，不只專有名詞一個都不漏，更用最詳盡且貼近生活的比喻，帶你徹底打通 AI 的核心技術脈絡！

1. 初階入門篇：人機日常對話與多媒體生成基礎

在第一階段，我們衡量的是身為終端使用者，在平日使用 ChatGPT、Claude、Midjourney 或各類影片生成工具時，是否具備正確的溝通直覺與基礎觀念。很多人以為只要把字打進去就是懂 AI，但如果連計費單位、記憶極限與基礎生成模式都不理解，產出的成果往往容易失控且浪費時間：

💬 語言模型日常對話詞彙

1. Prompt (提示詞)：
【白話比喻】向神燈精靈許願時所念的「願望清單」。
【深入解析】Prompt 不只是輸入一句話，而是引導模型內部神經元注意力權重分佈的指令文本。初學者往往只會丟出一句「幫我寫企劃」，而熟練的使用者懂得提供明確的背景脈絡、輸出格式（如條列或表格）與邊界條件，大幅降低盲目摸索的次數。

2. System Prompt vs. User Prompt (系統提示詞 vs. 使用者提示詞)：
【白話比喻】演員上台前導演給的「人設劇本」vs. 台下觀眾現場給的「隨堂考題」。
【深入解析】System Prompt 擁有最高權重，用來規範 AI 的根本性格、語言風格、安全規範與核心禁忌（例如「你是一名精通台灣法規的律師，一律以繁體中文回答」）；User Prompt 則是我們每次在對話框中輸入的具體提問。兩者分離能確保 AI 在長時間交談中不跑調。

3. Zero-Shot / One-Shot / Few-Shot (零樣本／單樣本／少樣本提示)：
【白話比喻】完全不給範例直接上考場 vs. 考前給一到三題範例參考答案。
【深入解析】Zero-Shot 是直接下達指令不給範例；Few-Shot 則是在提問前，先在 Prompt 裡附上兩到三個「輸入與期望輸出」的範例。研究證明，Few-Shot 能透過上下文學習 (In-Context Learning) 瞬間讓模型看懂複雜格式，精準度提升數倍。

4. Token (詞元／標記)：
【白話比喻】去麵館點餐時按「粒」計算的水餃。
【深入解析】電腦的大腦裡沒有中文字或英文字母，只有數字編號。模型在接收文字時，會透過分詞器（Tokenizer）將句子拆解成碎片，這個最小處理單元就是 Token。英文一個單字大約折合 1.3 個 Token；而繁體中文由於編碼特性，一個中文字常被切成 1 到 3 個 Token，這也是中文對話往往比英文消耗更多 API 費用與額度的根本原因。

5. Context Window (上下文窗口／記憶長度)：
【白話比喻】書桌上攤開的「便條紙大小」。
【深入解析】指模型單次對話中能同時「記住並運算」的 Token 總量上限。如果便條紙寫滿了，系統為了騰出空間寫下新字，就必須把最早以前的內容裁切撕除。一旦對話長度超出窗口，模型就會出現遺忘初期設定、前言不對後語的現象。

6. Streaming (串流輸出)：
【白話比喻】像打字機一樣逐字敲出，而不是等整本書寫完才一次端出來。
【深入解析】大語言模型本質上是一個字接一個字生成。串流技術利用伺服器發送事件 (SSE)，將剛出爐的每個 Token 即時回傳到使用者的螢幕上，極大緩解使用者等待完整回答時的焦慮感。

7. Max Tokens & Stop Sequences (最大長度與停止標記)：
【白話比喻】考卷規定最多寫五百字，以及作文結尾標上的「句號完畢」。
【深入解析】Max Tokens 強制限制單次輸出的最大字數上限以防費用爆表；Stop Sequences 則是設定特定符號（如「<END>」或換行），一旦模型生成該符號就立刻強制煞車停止作答。

8. Hallucination (幻覺)：
【白話比喻】面試時不懂裝懂、神情自若一本正經瞎掰的應徵者。
【深入解析】語言模型是依據統計機率預測下一個字，追求的是文意流暢而非事實查核。當模型遇到知識盲區或被誘導時，會以極度自信權威的口氣捏造出不存在的法規、文獻或歷史事件，這是日常使用中最需留意的陷阱。

9. Multimodal (多模態)：
【白話比喻】具備眼觀四面、耳聽八方能力的全方位特助。
【深入解析】早期的 AI 只能輸入文字，現在的多模態模型能將照片、圖表、音訊與影片投影到同一個高維語義特徵空間中，實現看懂手繪草稿直接寫出前端網頁程式碼的強大能力。

🎬 影音生成日常核心概念

1. T2I / I2I (文生圖／圖生圖)：
【白話比喻】口述請畫家憑空作畫 vs. 拿著參考草稿請畫家潤飾重繪。
【深入解析】影音生成的原點。T2I 純粹依賴文字從高斯雜訊生成靜態畫面；I2I 則是將現有圖片加入部分雜訊後重新引導去噪，保留原圖構圖輪廓但替換材質或藝術風格。

2. T2V (Text-to-Video，文生影片)：
【白話比喻】給導演一句簡短故事大綱，讓他自由發揮想像拍片。
【深入解析】純文字生影片，由演算法無中生有地建立動態環境、人物步伐與鏡頭運動。自由度極大，但隨機性過高，角色長相與背景細節每一次生成都有所不同。

3. I2V (Image-to-Video，圖生影片)：
【白話比喻】拿一張靜態照片給魔術師，吹一口氣讓它動起來。
【深入解析】以單張圖片作為起始影格，接續推算時間軸上的物理動態。這是目前商業社群短片最核心的工作流，因為可以先在靜態圖中鎖定完美的商品外觀或人物面貌，再賦予自然的動態。

4. V2V (Video-to-Video，影片轉影片)：
【白話比喻】真人拍攝動作捕捉，再換上動漫或賽博龐克的外皮。
【深入解析】輸入一段實拍影片，模型保留原片中的人體骨架、相機運動節奏與空間結構，僅對視覺風格進行重新渲染，徹底解決純 AI 生成時肢體反常穿模的通病。

5. Seed (隨機種子碼)：
【白話比喻】雜訊大理石原料庫的「出廠批號編號」。
【深入解析】生成模型本質是從亂數雜訊中雕琢畫面。固定 Seed 數值（如 123456），在相同提示詞下每一次都能產出構圖、色調與特徵極為一致的畫面，是進行對比實驗與保持角色穩定的關鍵。

6. Motion Strength (動態幅度／強度)：
【白話比喻】調整畫面吃了多少「能量飲料」的旋鈕。
【深入解析】控制影格之間物體或運鏡位移的劇烈程度。數值過低畫面形同微風吹拂的簡報幻燈片；數值過高則容易引發人體扭曲、肢體撕裂與背景崩解。

7. Negative Prompt (負向提示詞)：
【白話比喻】給廚師看的「忌口清單」（不要辣、不要香菜）。
【深入解析】在去噪計算過程中扣除不希望出現的特徵方向。影音生成常用「模糊、多餘手指、重複影格、畫面抖動、肢體融合」來壓制變異缺陷。

8. Prompt Weight (提示詞權重)：
【白話比喻】用螢光筆將課本特定句子畫粗線重點標記。
【深入解析】在語法中使用括號或數值加權（如 (tiffany blue:1.3)），指示模型分配更多交叉注意力給該概念，確保核心特徵不被其他描述稀釋。

9. Aspect Ratio & FPS (長寬比與每秒影格數)：
【白話比喻】畫布形狀與手翻書翻動的頻率。
【深入解析】長寬比決定是適合短影音平台的 9:16 還是橫向 16:9。FPS 則是每秒靜態影格數，原生影片模型受限於算力多產出 16~24 FPS，後續常搭配獨立升頻軟體插值至 60 FPS。

2. 中階工程篇：精準控制、檢索整合與一致性鎖定

到了中階階段，代表使用者已經脫離了單純「拼運氣抽卡」的入門期，開始追求確定性與可重現的工業化成果。在文字系統中，重點是如何將私有資料庫與 API 整合；在影音生成中，核心則是精準鎖定鏡頭運動與角色的時空特徵：

🛠️ 系統整合與控制中樞

1. RAG (檢索增強生成)：
【白話比喻】閉卷死背考試 vs. 帶整套企業百科全書進考場開卷應試。
【深入解析】傳統模型只能靠訓練時死背的靜態記憶。RAG 是在使用者發問瞬間，系統先自動到外部私有文件庫搜尋相關段落，再將該資料連同問題組裝交給 LLM 進行歸納作答，徹底根除幻覺且成本極低。

2. Embedding (向量嵌入)：
【白話比喻】給世間萬物發一張「多維度語義 GPS 身分證」。
【深入解析】演算法將文字或多媒體語義轉換為一串浮點數陣列（如 1536 維）。在該幾何空間中，意義相近的詞彙（例如「手搖飲」與「珍珠奶茶」）彼此距離極近，讓電腦獲得了計算抽象語義相似度的能力。

3. Vector Database (向量資料庫)：
【白話比喻】專門追蹤幾何座標的高速雷達站。
【深入解析】傳統 SQL 資料庫只能做字面完全相符比對；向量資料庫（如 Chroma、Pinecone）儲存的是向量，能在毫秒級速度下自數百萬份文件中找出語義最接近的內容段落。

4. Temperature、Top-P 與 Top-K (隨機採樣三劍客)：
【白話比喻】調校助手是「嚴肅會計師」還是「狂野藝術家」的控制閥。
【深入解析】Temperature 控制機率平滑度（越低越確定保守）；Top-P（核採樣）只在累積機率達到前 P%（如 90%）的候選詞中挑選；Top-K 則將候選詞強行鎖定在機率最高的前 K 個，三者協同杜絕胡言亂語。

5. Chunking & Re-ranking (切片與重排序)：
【白話比喻】把厚字典切成好讀章節，再由資深助教挑出最關鍵的三頁。
【深入解析】RAG 落地成敗關鍵。Chunking 將超長文章切分成具備語義邊界的段落；Re-ranking 則在初步粗篩出幾十筆資料後，用更精密的交叉編碼器精確重新打分排序，大幅提升檢索命中率。

6. Function Calling / Tool Use (函式呼叫／工具使用)：
【白話比喻】大腦動念頭時，手腳自動伸出去拿計算機或按電梯。
【深入解析】模型不再只是輸出聊天文字，而是能自主判斷並輸出符合 JSON 格式的函式參數，交由系統調用天氣 API、查閱資料庫或送出訂單，是大腦與真實世界接軌的橋樑。

7. AI Agent (智慧代理人)：
【白話比喻】具備獨立出差辦公能力的專業主管特助。
【深入解析】Agent 賦予了大腦三大能力：規劃目標 (Planning)、長期記憶 (Memory)、以及使用工具 (Tool Use)。面對複雜目標，能自主反思並一步步拆解執行，無須人類在每個步驟介入。

🎥 鏡頭語言與時空一致性

1. Camera Motion Control (虛擬運鏡控制)：
【白話比喻】片場軌道攝影師手中的多軸控制搖桿。
【深入解析】精準以指令操控相機空間運動：Pan（水平橫搖）、Tilt（垂直俯仰）、Zoom（鏡頭推拉變焦）、Roll（軸向翻轉旋轉）與 Orbit（以主體為核心環繞拍攝），賦予畫面專業電影級的節奏感。

2. First & Last Frame (首尾幀控制／關鍵幀約束)：
【白話比喻】定好起跑點與終點線，讓動畫師把中間的過渡動作平順補齊。
【深入解析】同時指定影片的起始圖與結尾圖，強制神經網路在兩張靜態畫面的空間幾何間計算出合乎物理定律的運動軌跡，是製作高品質無縫循環動畫與轉場的核心技術。

3. Temporal Consistency (時間一致性)：
【白話比喻】演員走兩步路不能突然換了張臉、衣服條紋突然變色。
【深入解析】AI 影音生成領域公認最艱鉅的指標。指影片在播放數秒內，主角五官特徵、衣服紋理、以及環境光源在視角轉換與位移中，依然維持高度連貫且不發生突變崩解的能力。

4. Flickering (畫面閃爍／高頻抖動)：
【白話比喻】日光燈管壞掉時惱人的微幅跳動感。
【深入解析】相鄰影格像素在微觀層級上的預測缺乏平滑度，導致播放時物件邊界、細緻髮絲或陰影出現不規則的微幅跳躍與高頻閃爍，為早期擴散模型常見瑕疵。

5. Inpainting & Outpainting (時空局部重繪與擴圖)：
【白話比喻】動態隱形斗篷與動態廣角延伸鏡頭。
【深入解析】Inpainting 能在時間軸上鎖定動態遮罩，精準抹除影片中穿幫的雜物或替換角色配件；Outpainting 則能將原本拍窄的 9:16 直式短片向兩側自動延伸出符合透視的 16:9 電影級全景。

6. ControlNet / IP-Adapter (條件約束引導)：
【白話比喻】給奔騰的野馬套上最堅固精準的韁繩。
【深入解析】在開源工作流如 ComfyUI 中，透過人體骨架圖 (OpenPose)、深度圖 (Depth) 或邊緣線稿 (Canny)，強制每一影格嚴格依循真人動作移動，達到商業化精準交付。

3. 模型型號與命名譜系大解密：參數、架構與量化版本

當我們在開源平台或各家雲端 API 挑選模型時，名稱裡總會夾帶一長串宛如外星密碼的字尾。這些字眼直接決定了模型的「腦容量」、「運算代價」、「訓練階段」與「硬體顯存需求」。搞懂這套命名譜系，是邁入進階技術人員的必修學分：

🏷️ 參數量級與激活機制 (B / A / MoE)

1. 「B」代表什麼？(Billion，十億參數)：
【白話比喻】大腦神經突觸節點的總數量。
【深入解析】B 代表十億。神經網路中每個權重都是一個浮點數。常見規格有：
• 1.5B ~ 3B：輕量端側模型，適合手機或樹莓派等極低功耗裝置。
• 7B ~ 8B：經典開源黃金起點，單張消費級顯卡（如 16GB）即可跑得動，能應付日常對話。
• 14B ~ 35B：甜點級性能，邏輯推理接近旗艦，4-bit 量化後能塞入 24GB 顯存的單張旗艦顯卡。
• 70B+：開源旗艦梯隊，常識與編程實力超群，需多卡或高規格伺服器部署。

2. Dense (稠密) vs. Sparse MoE (稀疏混合專家)：
【白話比喻】一人全包處理所有問題 vs. 組建跨科別顧問團輪流上陣。
【深入解析】傳統 Dense 模型（如 Llama 3 70B）每處理一個字，所有 70B 參數都全體動員；而 MoE 模型將網絡拆解成多個專門子網絡，推論時僅激活少數專家，算力大幅節省。

3. 「A3B / A14B」代表什麼？(Activated Parameters，激活參數)：
【白話比喻】公司編制有一百名員工，但單次專案會議只要抽派 3 位最懂的人出席。
【深入解析】在 MoE 架構中，A 代表「單次計算實際激活的參數量」。例如某模型總體積高達 16B（代表儲存了 16B 等級的龐大知識庫），但標示為 A3B，意味著它推論時只耗費相當於 3B 模型的運算量與極低延遲，兼顧容量與速度。

4. 「8x7B / 8x22B」代表什麼？：
【白話比喻】由八名專科醫師組成的聯合門診。
【深入解析】源自知名模型 Mixtral 8x7B。它並非單純將 8 個獨立 7B 模型疊加（實際總參數量約 46.7B），每次輸入一個詞，路由器會動態挑選表現最優的 2 位專家協同運算，推論速度等同於處理約 12.9B 的模型，大幅擊敗同速度的稠密模型。

🧬 訓練階段、功能後綴與量化代碼

1. 訓練階段代號 (Base / SFT / Instruct / RLHF / DPO)：

  • Base (基座版)：純文字接龍訓練出的原始模型，不會聽指令回答，僅適合拿來做繼續預訓練或特殊領域微調。
  • SFT (監督微調版)：吃過大量優質「問答對」資料集的半成品，開始懂得一問一答。
  • Instruct / Chat (指令對齊版)：經過人類指令對齊與安全性強化的成品，能直接在交談框中流暢對答。
  • Reasoning / R1 / Think (深度推理版)：搭載隱式或顯式思維鏈，在輸出答案前會自主進行深度推導與自我驗證。

2. 專長與功能後綴 (VL / Coder / Math / Uncensored)：

  • VL (Vision-Language)：具備視覺能力的多模態模型，能直接識別圖片內容。
  • Coder / Code：針對海量程式碼庫進行特化微調，精通各類程式語言。
  • Uncensored (未審查版)：開源社群移除了道德安全護欄與敏感詞限制的版本，但也伴隨一定安全風險。
  • Distill / Merged：利用大模型知識蒸餾出的精簡版，或透過演算法將多個不同模型權重融合一體的產物。

3. 商業產品階級名稱 (Mini / Flash / Pro / Max / Ultra)：
商業廠商常使用的層級分工。例如 Flash/Mini 代表極致追求低延遲與極低 API 成本的小模型；Pro 代表全方位能力均衡的工作主力；Max/Ultra 則是不計成本追求頂尖推理能力的旗艦重器。

4. 精度與量化格式 (FP16 / BF16 / GGUF / AWQ / Q4_K_M)：

  • FP16 / BF16：16 位元半精度浮點數，訓練與未壓縮推論的標準格式，每 1B 參數約吃 2GB 顯存。
  • GGUF：專為 CPU/GPU 混合推論（如 llama.cpp、Ollama）打造的單一二進位檔案格式。
  • Q4_K_M / Q5_K_M：GGUF 中的 4-bit / 5-bit 量化等級，在體積與精度流失間取得最佳平衡。
  • AWQ / EXL2：針對 GPU 記憶體頻寬深度優化的 4-bit 量化格式，推論速度極快。

4. 高階架構篇：自注意力機制、擴散黑盒子與世界模型

當討論推進至高階層次時，話題不再局限於外部工具拼裝，而是深入到模型內部的神經網絡拓撲與數學本質。你將看懂為什麼 Transformer 能一統江湖、擴散模型如何從混沌中提煉動態，以及 DiT 與流匹配技術為何能帶領影音生成迎來跨時代躍進：

🧠 語言模型核心拓撲與對齊機制

1. Transformer & Self-Attention (自注意力機制)：
【白話比喻】全班同學同時環顧四周，打量評估彼此間的關聯。
【深入解析】現代 LLM 的基石。過去的 RNN/LSTM 只能逐字閱讀，容易遺忘且無法平行運算；Self-Attention 利用 Query、Key、Value 三大矩陣，讓句子中所有詞彙在輸入瞬間同時計算關聯權重，破除循序限制，開啟了大規模平行訓練的時代。

2. MHA vs. GQA (多頭注意力 vs. 分組查詢注意力)：
【白話比喻】每位主管各配一名秘書 vs. 多位主管共用一名秘書小組。
【深入解析】MHA 讓每個 Attention Head 擁有獨立的 Key/Value，顯存負擔巨大；GQA（分組查詢注意力）將多個 Query Head 分組共享同一組 Key/Value 矩陣，在極微小精度損失下，大幅砍半 KV Cache 顯存消耗，是現代如 Llama 系列標配架構。

3. RLHF (人類反饋強化學習)：
【白話比喻】馴獸師拿著哨子與零食，獎勵聽話海豚、修正不良動作。
【深入解析】透過專業標註員對模型不同回答進行優劣評分，訓練出一個「獎勵模型 (Reward Model)」，再經由 PPO 等強化學習演算法引導大模型，使其回答不僅知識正確，更符合人類道德規範與安全底線。

4. LoRA & QLoRA (低秩適應與量化微調)：
【白話比喻】不改造大巨蛋本體鋼骨，只在旁邊加裝可隨時拆裝的外掛鷹架。
【深入解析】高效微調 (PEFT) 典範。LoRA 凍結原模型龐大參數矩陣，僅在旁側掛上兩個低維度分解小矩陣進行訓練；QLoRA 更進一步將基礎模型壓縮至 4-bit 後再掛載 LoRA，讓單張消費級顯卡也能輕鬆微調數百億參數的大模型。

5. MoE Architecture (混合專家底層路由)：
【白話比喻】醫院急診室分流處的資深分科導醫。
【深入解析】神經網絡包含多組前饋網絡 (FFN) 作為專家。推論時透過 Gating Network (門控路由演算法) 動態計算權重，每個 Token 只派送給得分最高的前兩位專家運算，用極小計算成本撬動海量參數量。

🌌 擴散數學機制與時空物理先驗

1. Denoising (去噪過程)：
【白話比喻】將起霧模糊的落地窗，一層一層擦拭乾淨顯露出窗外風景。
【深入解析】擴散模型的精髓。推論時從一整片高斯純雜訊出發，模型在數十個離散時間步 (Timesteps) 中，精確預測當前影格的噪聲分佈並加以扣除，逆向提煉出清晰細緻的影像。

2. DiT (Diffusion Transformer)：
【白話比喻】把老式蒸汽火車的引擎，直接換成噴射客機渦輪動力。
【深入解析】現代主流影片模型（如 Sora、Gen-3）的核心骨架。揚棄傳統卷積 U-Net，將影像與時序切成無數個時空小圖塊 (Patches) 當成 Token 丟進 Transformer 處理，徹底釋放算力與參數量帶來的擴展效益 (Scaling Law)。

3. Spatiotemporal Attention (時空注意力機制)：
【白話比喻】一隻眼緊盯單張畫面的透視，另一隻眼緊盯前後幾秒的動作位移。
【深入解析】將注意力拆解為「空間維度」（關注同一影格內立體結構）與「時間維度」（關注跨幀運動位移），交替運算以確保攝影機在劇烈旋轉運鏡時，三維幾何透視感完全不走樣。

4. 3D VAE (時空變分自動編碼器)：
【白話比喻】將整套高畫質電影膠卷抽取出核心骨髓的超強壓縮機。
【深入解析】未壓縮的 4K 影片資料量無比巨大，沒有硬體能直接在像素空間跑擴散。3D VAE 在長、寬與時間軸上同步進行高倍率無損壓縮，降維至潛在空間 (Latent Space)，讓後續的 DiT 網絡能輕鬆高效率運算。

5. Flow Matching (流匹配)：
【白話比喻】放棄曲折蜿蜒的山路，在雜訊與真實畫面間開鑿筆直高鐵隧道。
【深入解析】前沿生成架構採取的創新採樣範式。傳統隨機微分方程走的是迂迴曲線；流匹配透過建立筆直的常微分連續向量場，大幅減少計算步數，產出更自然流暢的動態。

6. World Model (物理先驗與世界模型能力)：
【白話比喻】即便沒學過微積分，觀察世界久了自然明白水會往下流。
【深入解析】神經網絡在吞噬數億段影片後，自主歸納出的隱式物理定律。模型開始理解重力、流體表面張力、光影遮擋與剛體碰撞反彈，被公認為通往通用人工智慧 (AGI) 的關鍵試金石。

5. 專家級推論優化篇：顯存管理、計算吞吐與平行運算

進入專家層次，焦點從「研發理論」徹底轉向「工業級落地運算」。這群架構師對抗的是 GPU 頻寬極限、顯存碎片化、以及如何將原本需要耗費數十秒的影音運算壓縮至秒級即時互動。以下專有名詞代表著當前產業界最前線的硬實力：

⚡ 語言推論架構與硬體吞吐

1. KV Cache (鍵值快取)：
【白話比喻】收銀檯旁的熟客便條紙，不必每次結帳都重新盤問姓名。
【深入解析】自回歸模型生成下一個字時，原本需將前面所有文字全部重新計算一次。KV Cache 將已計算出的 Key/Value 矩陣常駐在顯存中，新 Token 只要計算自己並調用快取，是推論加速數十倍的基本生命線。

2. FlashAttention & PagedAttention：
【白話比喻】工廠極速快取調度大師與作業系統記憶體分頁管理員。
【深入解析】FlashAttention 精準調度 GPU 內超快 SRAM 與顯存 HBM 的讀寫，消除傳輸瓶頸；PagedAttention 借鑑虛擬記憶體分頁機制，將零碎顯存無縫拼接，是高併發推論框架（如 vLLM）解決長文本顯存溢出的救星。

3. Loss Function & Gradient Descent (損失函數與梯度下降)：
【白話比喻】在濃霧山谷中摸索下坡路，每一步都往最低窪的目標前進。
【深入解析】神經網路訓練之本。損失函數衡量預測與真實標籤之誤差；反向傳播計算梯度，AdamW 等優化器據此更新數百億參數，使整體誤差逐步收斂至最低。

4. DPO (Direct Preference Optimization，直接偏好優化)：
【白話比喻】主管直接在兩份作業中打勾叉，捨棄繁複的第三方裁判。
【深入解析】DPO 在數學上嚴密證明能跳過傳統單獨訓練獎勵模型的複雜流程，直接利用人類偏好數據定義隱式損失函數，大幅降低對齊訓練崩潰的不穩定風險。

5. TTFT 與 TPS (推論效能雙指標)：
【白話比喻】點餐後「出第一道菜的時間」與「後續每分鐘端上菜盤數」。
【深入解析】TTFT（Time to First Token）反映首字延遲，影響等待焦慮；TPS（Tokens Per Second）衡量生成吞吐速度，決定文字流絲滑度與伺服器承載並發上限。

🎞️ 影音極限管線部署與調校

1. Temporal CFG (時序無分類器引導)：
【白話比喻】隨著交響樂演奏進度，動態調整指揮棒的揮動力道。
【深入解析】影片生成若全程維持過高 CFG 數值，畫面越往後越容易過曝焦黑；Temporal CFG 在時間軸上動態遞減或微調強度，確保鏡頭聽話的同時肢體能自然舒展。

2. Frame Interpolation (智慧影格插值技術)：
【白話比喻】在每兩張手繪稿中間，由速寫大師依據光流補繪過渡幀。
【深入解析】讓擴散模型僅渲染 15 FPS 基礎畫面，再藉由光流模型（如 RIFE、FILM）在毫秒內自動補算至 60 FPS，省下天價渲染成本並獲得極致絲滑動態。

3. Consistency Distillation / LCM (一致性模型蒸餾)：
【白話比喻】傳授絕世輕功，將原本三十步的登頂過程縮成三步飛躍。
【深入解析】LCM 透過一致性蒸餾，迫使模型在常微分軌跡上的任何一點都能直接預測最終成像，僅需 2 到 4 步即可成像，敲開了實時互動式生成影片的大門。

4. Context Parallelism / Ring Attention (環狀長序列平行運算)：
【白話比喻】圍成一圈傳遞接力棒的高速協同隊伍。
【深入解析】生成長達數十秒的高畫質影片時，時空注意力計算複雜度暴漲。Ring Attention 將時序資料切片分散於多張顯卡叢集上，邊算局部注意力邊環狀傳遞 Key/Value，成功跨越顯存天花板。

5. Motion Blur & Shutter Speed Emulation (動態模糊與快門模擬)：
【白話比喻】為數位動畫注入實體電影膠卷特有的光學靈魂。
【深入解析】AI 逐格生成的物體邊緣常因過度銳利而帶有廉價電玩感；透過在潛在空間模擬實體攝影機 180 度快門殘影，賦予主體高速運動真實拖影，達到難辨真偽的院線質感。
