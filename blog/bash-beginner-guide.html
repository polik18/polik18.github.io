1. 什麼是 Bash？你的電腦專屬「全能管家兼翻譯官」

平常我們使用 Windows 或 macOS 時，習慣用滑鼠點擊圖示、開啟資料夾或拖曳檔案，這種視覺化操作方式稱為圖形化使用者介面（GUI, Graphical User Interface）。雖然直覺，但如果要一次把 1,000 個檔案重新命名，滑鼠點擊就會讓人崩潰。

而 Bash（全名 Bourne Again SHell） 則是另一種與電腦深度溝通的方式——文字命令列介面（CLI, Command Line Interface）。它是 Unix 與 Linux 系統中最核心、普及度最高的指令解譯器與腳本程式語言。

💡 生活化比喻：管家與任務卡

你可以把 Bash 想像成一位效率極高、說一不二的專屬管家：
• 互動模式（即時聽令）： 你在終端機輸入一句指令（例如「列出桌面的所有照片」），管家瞬間翻譯給作業系統核心執行，並把結果顯示在螢幕上。
• 腳本模式（自動代辦）： 你可以把一整天的繁瑣任務寫在一張任務清單（.sh 檔案）中交給管家，讓他每天定時自動跑完整套流程，這就是 Shell Script。

2. 新手必學！日常檔案與系統操作核心指令

在終端機中，所有的操作都是透過輸入簡短精悍的「指令」來完成。掌握以下這幾組核心指令，就能應付 80% 以上的日常檔案管理與伺服器巡檢需求：

分類指令白話功能說明常見實用範例
路徑與檔案pwd印出目前所在完整路徑（我在哪？）pwd
路徑與檔案ls列出目前資料夾內容（這裡有什麼？）ls -la（顯示詳細權限與隱藏檔）
路徑與檔案cd切換工作目錄（換房間）cd ..（回上一層）、cd ~（回家目錄）
檔案管理mkdir建立全新資料夾mkdir -p project/src（多層自動建立）
檔案管理touch建立空白檔案或更新修改時間touch index.html
檔案管理cp複製檔案或整份目錄cp -r photo_backup /Volumes/ExtDisk
檔案管理mv移動檔案或重新命名mv old_name.txt new_name.txt
檔案管理rm刪除檔案（不經垃圾桶，永久抹除）rm -rf temp_folder（強制遞迴刪除）
內容檢視cat / less快速印出或分頁瀏覽文字檔cat log.txt、less bigfile.csv
內容檢視tail檢視檔案末尾幾行或即時監控tail -f error.log（即時監看伺服器日誌）
文字搜尋grep如同螢光筆抓取含有關鍵字的行grep "404" access.log

3. 管線與重導向：把指令組裝成高效自動化生產線

Bash 之所以被全球工程師熱愛超過三十年，核心威力就在於管線（Pipeline |）與輸出重導向（> / >>）機制。你可以將每個輕量小工具組合串接，瞬間變成一條強大的資料處理生產線！

🔗 管線 Pipeline ( | )

將前一個指令產生的結果，無縫傳遞給下一個指令當作輸入原料。
範例： cat app.log | grep "FATAL" | wc -l
（讀取記錄檔 ➜ 篩選嚴重錯誤 ➜ 計算總共有幾筆）

📥 覆寫輸出 ( > )

將螢幕上要印出的文字直接儲存並覆蓋至指定檔案。
範例： echo "系統啟動成功" > status.txt
（如果檔案已存在，會清除舊內容並重新寫入）

➕ 附加輸出 ( >> )

將執行結果安全地附加在檔案最後一行，不破壞舊紀錄。
範例： date >> system_history.log
（持續記錄每次執行的時間戳記）

⚡ 條件串接 ( && )

前一個指令成功執行完畢，才會啟動下一個指令。
範例： npm run build && git add .
（專案順利打包完成後，才自動加入版本控制）

4. 效率翻倍！不能不知的終端機神級快捷鍵

在黑底白字的文字介面中，還在按老半天方向鍵慢慢移動游標嗎？快把這幾組超實用的快捷鍵記起來，操作速度立刻提升好幾倍：

操作類別快捷鍵組合功能解析與使用情境
游標移動Ctrl + A / Ctrl + E瞬間將游標移至整行「最前端」或「最尾端」
單詞跳躍Alt + F / Alt + B游標依序向前（Forward）或向後（Backward）跨單詞跳躍
快速清除Ctrl + U / Ctrl + K剪下並清空游標至行首（Ctrl+U）或至行尾（Ctrl+K）的文字
刪詞與貼上Ctrl + W / Ctrl + Y刪除游標前的一個單詞，或貼上剛剛剪下的內容（Yank）
智慧補齊Tab自動補齊指令或路徑檔名（連按兩下顯示所有可能清單）
歷史搜尋Ctrl + R反向搜尋歷史指令庫，輸入關鍵字即時抓回曾跑過的長代碼
緊急煞車Ctrl + C強行中斷目前執行中的程式或卡住的程序
螢幕整理Ctrl + L清空螢幕畫面（同 clear 指令，但游標位置更順暢）

5. 進入自動化世界：手把手寫出第一個 Bash 腳本

當你需要重複執行多個指令時，把它們寫成腳本（Shell Script）就能實現「一鍵自動化」。編寫 Bash 腳本只需掌握四大基本元件：

Step 1：腳本起手式與執行權限

建立副檔名為 .sh 的檔案（例如 hello.sh），第一行必須加上 Shebang 宣告：

#!/bin/bash
# 這是我的第一支自動化腳本
echo "恭喜你！成功啟動第一個 Bash Script！"

在終端機賦予檔案執行權限並啟動它：

chmod +x hello.sh   # 賦予可執行權限
./hello.sh          # 執行腳本

Step 2：變數宣告（等號兩側絕對不能有空格）

在 Bash 中定義變數非常簡單，但請務必注意：等號 = 左右兩端嚴禁留空格！

APP_NAME="AutoReporter"
CURRENT_USER=$(whoami)               # 將系統指令執行結果存入變數
TODAY=$(date +"%Y-%m-%d")

echo "專案名稱：${APP_NAME}"
echo "目前操作者：${CURRENT_USER} | 執行日期：${TODAY}"

Step 3：條件判斷（If-Else 結構）

條件判斷式使用中括號 [ ] 包裹，且中括號內側前後必須保留一個空格，並以 fi（if 的倒寫）作為結束：

TARGET_DIR="./data_backup"

# -d 代表檢查「是否為存在的目錄」
if [ -d "$TARGET_DIR" ]; then
    echo "[✔] 備份目錄已存在，準備寫入..."
else
    echo "[!] 找不到目錄，自動為您建立：$TARGET_DIR"
    mkdir -p "$TARGET_DIR"
fi

Step 4：迴圈處理（For / While 批次跑資料）

當有一整批檔案或清單要處理時，迴圈是最好的省力幫手：

# 範例：批次處理多個伺服器節點巡檢
NODES=("web-server-01" "db-server-01" "cache-node-01")

for NODE in "${NODES[@]}"; do
    echo "正在巡檢節點狀態：${NODE} ... 正常運行中"
done

6. 實戰演練：打造一鍵自動備份小助理

現在，我們將上述學到的變數、判斷式、迴圈與輸出重導向完整融會貫通，組裝成一支真正能幫你在日常工作中節省大量時間的自動化備份腳本：

#!/bin/bash

# ========================================================
# 專案：每日關鍵檔案自動備份助理
# ========================================================

BACKUP_ROOT="./daily_backups_$(date +%Y%m%d)"
DOCUMENTS=("config.env" "database.sqlite" "report.pdf")

echo "=== [1/3] 開始執行自動化備份排程 ==="

# 檢查備份目的地目錄是否存在
if [ ! -d "$BACKUP_ROOT" ]; then
    mkdir -p "$BACKUP_ROOT"
    echo "[+] 成功建立今日備份主目錄：$BACKUP_ROOT"
fi

echo "=== [2/3] 正在逐一驗證並備份檔案清單 ==="

for FILE in "${DOCUMENTS[@]}"; do
    if [ -f "$FILE" ]; then
        cp "$FILE" "$BACKUP_ROOT/"
        echo "  [✔] 成功備份：$FILE -> $BACKUP_ROOT/"
    else
        echo "  [✖] 略過：找不到來源檔案 $FILE"
    fi
done

# 產生備份紀錄日誌
echo "備份任務完成於 $(date) 由使用者 $(whoami) 執行" > "${BACKUP_ROOT}/backup_summary.txt"

echo "=== [3/3] 恭喜！所有檔案備份任務已順利達成！ ==="

7. 常見問題與技術操作安全須知

學習 Bash 不必強記所有的參數選項，只要將常用指令與快捷鍵內化為肌肉記憶，並在日常工作中逐步嘗試用腳本取代重複的滑鼠點擊，你就會發現命令列世界的強大與優雅！

⚠️ 技術操作與指令執行安全聲明本文章所提供之 Bash 指令、Shell 腳本及系統維運操作範例僅供技術教學與個人學習參考。在終端機中執行刪除指令（如 rm -rf）、權限變更（chmod）或批次覆寫操作時，請務必再三確認檔案路徑與參數設定。終端機刪除操作並不會移至資源回收筒，對於因指令輸入錯誤、路徑不當或腳本邏輯疏漏所導致之檔案遺失或系統異常，讀者需自行評估並承擔操作風險，強烈建議在正式執行前先完成完整資料備份。
