SEATING & ROSTER01

Classroom Seat Master

從學生名單、性別規則、特殊座位到抽籤展示，完整處理一張座位表的生命週期。適合導師、科任教師與需要公開展示座位結果的班級。

  • 本機儲存
  • Excel 貼上
  • 中英雙語
  • 公平洗牌
  • 自由設定座位網格、走道、缺號與學生資料欄位
  • 男女橫排、直行或棋盤交錯一鍵配置
  • 黑板、門、老師座位與整間教室旋轉
  • 預排特殊座位、抽後交換及展示模式
  • JSON 匯入匯出，資料主要保留於目前瀏覽器
  • 桌面與手機版介面，展示時隱藏管理規則
開啟座位編排工具
CLASSROOM SUITE02

智慧課堂助手系列

把抽籤、分組、倒數、計分、噪音偵測、白板與考場資訊整合在同一系列。基礎版適合快速開用，Pro 版提供資料管理與跨模組連動，考場頁則專注大螢幕資訊。

  • 抽籤分組
  • 課堂計時
  • IRS 互動
  • 考場看板
  • 號碼／姓名抽籤與不重複抽取
  • 小組倒數、課堂大鐘與番茄鐘
  • 小組及個人雙軌計分與噪音偵測
  • Pro 版名單、分組、計分資料連動
  • 考試科目、時間、監考與應到／實到資訊
  • 適合投影機或大型觸控顯示器

BROWSER WORKSPACE03

WebPad++

一個以瀏覽器為核心的多功能工作台，能處理網頁程式、Markdown、試算表、文件、OCR、QR Code 與基本 SEO 檢查。適合資訊課、臨時編輯與不方便安裝軟體的環境。

  • 程式預覽
  • 文件工具
  • OCR
  • SEO
  • CodeMirror 程式編輯、格式化與即時預覽
  • Markdown、XLSX、CSV、PDF、DOCX 工作流程
  • 瀏覽器端 OCR 與 QR Code 產生／解碼
  • sitemap、robots.txt 與 HTML SEO 輔助
  • 資料以瀏覽器儲存為主，可自行匯出
  • 支援多語介面與本地優先依賴載入
開啟 WebPad++

When to use

從教學流程選工具

課前

整理名單與空間

用 Seat Master 匯入名單、配置限制與確認展示方向，再匯出班級設定備份。

課中

維持節奏與參與

使用智慧課堂助手抽籤、分組、倒數及計分，降低在多個工具間切換的成本。

備課

臨時處理數位素材

用 WebPad++ 編輯網頁、讀取文件、辨識圖片文字或快速產生 QR Code。
