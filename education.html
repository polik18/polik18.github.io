SEATING & ROSTER01

Classroom Seat Master

從學生名單、性別規則、特殊座位到抽籤展示，完整處理一張座位表的生命週期。適合導師、科任教師與需要公開展示座位結果的班級。

  • 本機儲存
  • Excel 貼上
  • 中英雙語
  • 公平洗牌
  • 自由設定座位網格、走道、缺號與學生資料欄位
  • 男女橫排、直行或棋盤交錯一鍵配置
  • 黑板、門、老師座位與整間教室旋轉
  • 預排特殊座位、抽後交換及展示模式
  • JSON 匯入匯出，資料主要保留於目前瀏覽器
  • 桌面與手機版介面，展示時隱藏管理規則
開啟座位編排工具

  • 抽籤分組
  • 課堂計時
  • IRS 互動

  • 小組及個人雙軌計分與噪音偵測
  • Pro 版名單、分組、計分資料連動
  • 考試科目、時間、監考與應到／實到資訊

AUTHENTICATED VOTING03

Polik Vote

以 Google 帳號驗證參與者的線上投票與表決平台，適合班級票選、校務意見與組織決策。管理者可以設定參與資格、票制、公布時機與通過門檻，參與者則在同一個清楚流程中完成投票。

  • Google 登入
  • 記名／不記名
  • 多種票制
  • CSV 匯出
  • 公開、Email 白名單與指定 Workspace 網域資格
  • 支援單選、多選及 N 票自由分配
  • 可設定截止時間、改票、法定人數與通過條件
  • 依需求控制即時、投票後或截止後公布結果
  • 管理員分工、參與紀錄、結果及 Audit Log
  • 使用 Firebase 與 Cloudflare，需 Google 帳號及網路連線

  • 互動式 3D
  • 作品分享
  • 展示模式

  • 瀏覽器即時渲染的 3D 展場預覽
  • 展廳、全螢幕與簡報三種展示模式
  • 班級、學生與作品 Dashboard 統計
  • 學生個人頁與作品專屬分享 URL 架構
  • 教師／學生角色及雲端同步 adapter 基線
  • 目前為架構預覽，正式雲端登入與權限待接入

BROWSER WORKSPACE05

WebPad++

一個以瀏覽器為核心的多功能工作台，能處理網頁程式、Markdown、試算表、文件、OCR、QR Code 與基本 SEO 檢查。適合資訊課、臨時編輯與不方便安裝軟體的環境。

  • 程式預覽
  • 文件工具
  • OCR
  • SEO
  • CodeMirror 程式編輯、格式化與即時預覽
  • Markdown、XLSX、CSV、PDF、DOCX 工作流程
  • 瀏覽器端 OCR 與 QR Code 產生／解碼
  • sitemap、robots.txt 與 HTML SEO 輔助
  • 資料以瀏覽器儲存為主，可自行匯出
  • 支援多語介面與本地優先依賴載入
開啟 WebPad++

When to use

從教學流程選工具

課前

整理名單與空間

用 Seat Master 匯入名單、配置限制與確認展示方向，再匯出班級設定備份。

課中與決策

維持節奏、參與和共識

使用智慧課堂助手進行抽籤、分組與計分；需要正式表決時，再用 Polik Vote 管理資格、票制與結果。

成果發表

把作品變成展覽

用 Class3D Gallery 呈現班級作品、切換展示模式，並準備作品分享入口。

備課

臨時處理數位素材

用 WebPad++ 編輯網頁、讀取文件、辨識圖片文字或快速產生 QR Code。
