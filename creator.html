Category 02 · Creator

從畫面與聲音，快速變成可以分享的內容。

三個工具分別處理擷取、視覺化與嵌入。核心工作盡量留在瀏覽器本機完成，適合教學錄製、社群素材、作品展示與網頁內容整理。

← 回專案總覽
CAPTURE01

Screenrecorder Pro

免安裝的螢幕錄影工作台，可選擇整個桌面、應用程式視窗或瀏覽器分頁，並混合麥克風、系統聲音與攝影機子母畫面。

  • 本機錄製
  • 雙軌混音
  • 攝影機 PiP
  • MP4／WebM
  • 螢幕、視窗與分頁三種擷取範圍
  • 系統音訊與麥克風即時混音
  • 可拖曳定位的攝影機子母畫面
  • 錄製暫停、繼續、計時與狀態提示
  • 完成後直接預覽與下載，不經專案後端
  • 最適合桌面版 Chrome 或 Edge
開始錄影
VISUALIZE02

Audio Visualizer 3D

將音樂頻譜轉成即時 3D 畫面，提供可操作的視覺參數與影片輸出流程。適合音樂封面動態化、教學示範、背景視覺與短影音素材。

  • Web Audio
  • Three.js
  • WebCodecs
  • MP4 輸出
  • 載入音訊後即時分析頻率與節奏變化
  • 以 WebGL 生成空間感視覺效果
  • 參數可即時調整並預覽結果
  • 透過瀏覽器編碼流程輸出影片
  • 免安裝專業剪輯軟體即可產生素材
  • 效能與輸出速度依裝置硬體而異
開啟視覺化工具
EMBED03

YouTube Shorts Embed

把 YouTube Shorts 分享網址整理成適合網站使用的 9:16 iframe 嵌入碼，提供尺寸、循環播放與說明文字選項。

  • 9:16 直式
  • 即時預覽
  • 一鍵複製
  • 自訂尺寸
  • 貼上 Shorts URL 自動辨識影片代碼
  • 即時預覽直式影片在網頁中的比例
  • 自由調整嵌入寬高與播放選項
  • 可加入影片說明文字
  • 一鍵複製 iframe 程式碼
  • 適合部落格、教材頁與作品集
產生嵌入碼

Creator flow

一條簡單的內容流程

01 · 擷取

錄下操作或講解

用 Screenrecorder 同時錄製簡報、旁白與攝影機畫面，完成第一版素材。

02 · 生成

建立音樂視覺

把聲音交給 Audio Visualizer，快速得到具節奏感的 3D 動態畫面。

03 · 發布

嵌入直式內容

將 Shorts 影片轉成可放入網站、教材或文章的響應式嵌入碼。
